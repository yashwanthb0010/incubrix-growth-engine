# Tools and AI Disclosure Statement
**Project:** IncuBrix AI-Powered Social Media Content Engine
**Candidate Assessment Submission — Option 2:** Social Media Marketing and Content Engine

## 1. Summary of Tools Used

### Core Programming & Backend Frameworks:
- **Python 3.14.3:** Primary programming language for all backend pipelines, data models, validation, and rendering orchestration.
- **Streamlit (v1.56.0):** Interactive web application dashboard providing multi-page navigation, data visualization, real-time generation controls, and approval workflows.
- **Pydantic (v2.12.5):** Strict data modeling, schema definition, type safety, and structured output parsing.
- **SQLite3:** Embedded relational database for persistent storage of inputs, generation runs, assets, and audit logs.
- **Pillow (v12.2.0):** High-resolution graphics rendering, typography calculation, contrast checks, and multi-slide carousel generation.
- **imageio-ffmpeg (v0.6.0 with FFmpeg v7.1 x86_64 binary):** Video encoding pipeline for generating real, playable 1080x1920 MP4 vertical videos.
- **OpenCV (v5.0.0.93):** Video property validation (duration, frame rate, aspect ratio, frame count).
- **Pandas (v3.0.2) & OpenPyXL (v3.1.5):** Structured data exports, Excel workbook generation with formulas, and CSV calendar formatting.
- **Pytest (v9.1.1):** Automated regression, edge-case, and compliance testing.
- **Git:** Version control and commit history.

## 2. Disclosure of AI Assistance

### Where AI Was Used:
1. **Architecture & Code Synthesis:** AI was utilized to draft initial module scaffolds (ingestion, generation, validation, persistence, Streamlit UI) and design system tokens.
2. **Deterministic Demo Mode Logic:** AI logic was used to design structured prompt templates and deterministic content extraction algorithms that synthesize platform-native hooks, captions, and slide decks from source documents.
3. **Research Synthesis:** Public information from incubrix.com, ZaubaCorp, and competitor profiles was processed and structured into comparative tables.

### Where AI Was NOT Used (Manual & Deterministic Engineering):
1. **Factual Verification:** Product claims and company legal existence were verified through public MCA corporate filings and live web indexation. No metrics or features were fabricated.
2. **Quality Validation Logic:** All 12 validation rules (duration, aspect ratio, UTM structure, duplicate detection, link verification) are deterministic rule-based algorithms.
3. **Audience Survey Data:** Survey protocols and analysis scripts were built deterministically; zero synthetic participants or responses were fabricated.
4. **Media Rendering Pipeline:** Video frames, progress bars, audio waveforms, typography layout, and slide numbers are rendered via explicit mathematical and graphic algorithms in Python.
